# Interface Parser

![logo](Resources/revenant_logo.png)

## Описание

**Interface Parser** — это утилита для автоматизации проверки статуса игроков на сервере для выдачи наказания. Программа предназначена для помощников администрации и позволяет массово проверять статус игроков (онлайн/офлайн) через анализ интерфейса игры.

Основной принцип работы базируется на распознавании цвета пикселей. Это обеспечивает стабильную работу программы независимо от установленных графических настроек, включая Reshade и ENB.

## Важное предупреждение

Внимательно ознакомьтесь с данной инструкцией перед использованием.

Использование программного обеспечения для автоматизации действий в панели администратора может внести непоправимые изменения при халатном обращении.


## Возможности

- Автоматический парсинг ID из буфера обмена.
- Распознавание статуса игрока через анализ цвета интерфейса.
- Поддержка различных графических настроек (работает с Reshade и ENB).
- Гибкая калибровка под разрешение экрана и положение интерфейса.
- Автоматическое определение задержки ввода в зависимости от версии Windows.
- Сохранение результатов проверки в отдельный файл.
- Проверка наличия запущенного процесса GTA5.exe перед началом работы.

## Системные требования

- Операционная система: Windows 10 или Windows 11.
- Игра: Процесс GTA5.exe должен быть запущен.
- Разрешение экрана: Рекомендуется стандартное масштабирование (100%), либо корректная настройка DPI в ходе калибровки.

## Установка

1. Создайте отдельную директорию для программы.
2. Скачайте актуальную версию исполняемого файла.
3. Запустите файл от имени администратора (рекомендуется для корректной работы с буфером обмена и вводными событиями).

## Настройка (Первый запуск)

При первом запуске программа перейдет в режим калибровки. Следуйте инструкциям в терминале:

1. Откройте панель администрирования для проверки ID.
2. Запустите утилиту.
3. Нажмите ENTER для начала настройки конфигурации.
4. Выберите версию операционной системы:
   - 1 для Windows 10 (задержка 30 мс).
   - 2 для Windows 11 (задержка 70 мс).
5. Калибровка координат:
   - **Позиция ввода ID:** Наведите курсор на строку ввода ID в панели администрирования и нажмите ENTER.
   - **Позиция проверки статуса:** Наведите курсор на пустую область рядом с вашим ником (справа) и нажмите ENTER.
   - **Позиция проверки меню:** Наведите курсор на текст "Не знание правил - не освобождает от ответственности" (или любой статический элемент меню) и нажмите ENTER.
6. Уберите курсор с панели управления и нажмите ENTER для завершения калибровки.
7. Программа сохранит конфигурацию в файл config.txt и завершит работу.

## Использование (Ежедневная работа)

1. Запустите GTA 5 и откройте панель администрирования.
2. Скопируйте первые два столбца - Кто выдал наказание + ID нарушителя. (так же и на банах)
3. **Важно:** Переключите вкладку браузера с таблицей на любую другую, чтобы фокус не находился на браузере во время работы скрипта. (для полной безопасности)
4. Запустите утилиту.
5. Если конфигурация загружена успешно, нажмите ENTER для начала проверки.
6. Программа автоматически обработает список ID из буфера обмена.
7. По завершении результаты будут сохранены в файл results.txt.
8. В терминале выберите действие:
   - Нажмите R для перезапуска проверки.
   - Нажмите Пробел для закрытия приложения.


## Структура файлов

После работы программы в директории создаются следующие файлы:

- config.txt — файл конфигурации. Содержит координаты элементов интерфейса, цветовые метки и тайминги. Не редактируйте вручную.
- ids.txt — временный файл, содержащий обработанный список ID из буфера обмена.
- results.txt — итоговый файл со списком ID игроков, которые находятся онлайн.
**Важно:** Очищать вручную ничего не нужно!
## Обработка данных

Программа автоматически фильтрует содержимое буфера обмена:
- Поддерживаются ID длиной от 3 до 6 цифр.
- Игнорируются пустые строки.
- Если строка содержит текст перед ID, программа попытается извлечь числовое значение.
- Дубликаты удаляются.
- Список сортируется перед записью.

## Решение проблем


**Программа закрывается с ошибкой "Процесс GTA5.exe не запущен"**
- Убедитесь, что игра запущена и вы находитесь на сервере.
- Проверьте имя процесса в диспетчере задач (должно быть точно GTA5.exe).

**Программа зависает на этапе проверки меню**
- Убедитесь, что панель администрирования открыта.
- Проверьте, не перекрывает ли курсор мыши элементы интерфейса, указанные при калибровке.
- Если вы изменили разрешение экрана или масштабирование, удалите файл config.txt и пройдите калибровку заново.

**Неверные результаты проверки (онлайн игроки не определяются)**
- Возможно, изменился цвет интерфейса из-за смены темы или графических настроек.
- Удалите файл config.txt и выполните повторную калибровку.

**Ошибка буфера обмена**
- Убедитесь, что вы скопировали текст перед запуском программы.
- Убедитесь, что вы запустили программу от администратора.

## Техническая информация

- Язык программирования: C++
- Библиотеки: Windows API, Standard Template Library (STL)
- Компиляция: Требуется линковка Shcore.lib для поддержки DPI awareness.
- Управление памятью: Автоматическое освобождение ресурсов буфера обмена и_handles.
